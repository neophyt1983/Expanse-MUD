SCREENSHOT AND CHANGES
The supplied phone screenshot shows wrapping full-length panel tabs, a partly

1. The phone layout is one active bounded panel, replacing fixed 65vh Conversation
   height and overflowing wrappers that allowed the surrounding page to grow.
2. Compact Talk / Map / Nearby tabs remain on one row; full titles are retained
   in accessible names. Optional Character is a fourth You tab.
3. A common Actions + Panels row serves every phone tab. Redundant panel title
   bars and desktop window chrome are removed from phone mode. Panels offers
   Hide/Show, Show all and Reset Layout, including recovery when all are hidden.
4. Header links stay on one row. Save, Tools and settings remain reachable in a
   horizontally scrolling session row. No automatic saves were introduced.
5. The command field has an accessible label, placeholder, 16px phone type,
   virtual-keyboard Send hint and a native Send button. Failed/disconnected or
   refused movement submissions preserve the draft. IME Enter cannot submit
   partially composed text. Touching Send preserves typing focus.
6. The workspace fits the visible viewport. Keyboard-sized or very short typing
   views collapse the header/status/session rows; Done restores the controls.
   Rotation and keyboard recovery preserve draft/caret. Pinch zoom is retained
   without shrinking the layout to the pinched visual rectangle.
7. Phone transcript text uses 16px system text with 1.5 line height and brighter
   system messages. Incoming text and quest offers preserve an older reading
   position; New messages jumps to the bottom. Your own submitted command also
   follows the newest response. clear/cls clears the unread badge.
8. Menus retain one Quests and one Newspaper. Typed legacy aliases still route
   to those same readers. Wider windows restore the existing desktop preference.
