# Multiplayer development status

**The public shared MMO world is not enabled.** Current hosted accounts are each isolated in their own Single Player world.

## Intended shared-world model

A future MMO/MUD session will connect each player to the same authoritative host world, with the host located on Render or on a player's computer. The host controls world state, mutations, character ownership, saved records and privileges.

## Release gate

Shared MMO must remain disabled until shared-world behavior, account isolation, editor authorization, persistence and multiplayer integration tests pass. A client cache of graphics, sprites or audio does not confer authority over game state.

## Status updates

The new official news channel is under development. Until it launches, check the [existing community forum](https://expansemud.discourse.group/) and the [independent status page](https://expansemud.com/status/) for published notices. A work-in-progress feature is not a released feature.
