# Multiplayer development status

**The public shared MMO world is not enabled.** Current hosted accounts are each isolated in their own Single Player world.

## Private shared sessions

Private shared sessions can connect multiple players to one host world with a host invite. Availability depends on the host and the client. The host controls world state, mutations, character ownership, saved records and privileges.

## Release gate

Shared MMO must remain disabled until shared-world behavior, account isolation, editor authorization, persistence and multiplayer integration tests pass. A client cache of graphics, sprites or audio does not confer authority over game state.

## Status updates

Read the [official announcements](https://expanse-mud.onrender.com/forum/c/news) or check the [independent status page](https://expansemmo.com/status/) for published notices. A work-in-progress feature is not a released feature.
