# Official News & Server Status — posting templates

Use the `Official News & Server Status` category for these. These are templates, **not claims about the live server**.

## Scheduled maintenance

Title: `[Maintenance] Expanse server maintenance — DATE, TIME CT`

When: DATE, TIME CT (include UTC if practical).

Why: A brief factual description of planned maintenance.

Impact: Game sign-in / sessions / downloads / community (specify).

Saved progress: Confirm the actual save procedure. Do not promise automatic saves without verifying it.

Next update: TIME CT, or say when you'll know more.

## Unexpected outage

Title: `[Investigating] Expanse game unavailable — DATE, TIME CT`

Current status: Confirmed unavailable / intermittent / under investigation.

Who is affected: Only what has been tested.

What we know: Observed errors without disclosing sensitive logs.

Player advice: Avoid retrying risky save/import actions until service health is confirmed.

Next update: TIME CT if known; otherwise post when the state changes.

## Resolved outage

Title: `[Resolved] Expanse game restored — DATE, TIME CT`

Restored at: Confirmed time and time zone.

Verification: Health check, actual login, character resume and persistence tests performed.

Cause: Confirmed or explicitly unknown.

Any remaining issue: List only verified remaining problems.

## New release

Title: `[Release] Expanse VERSION — What changed`

What is new: Specific verified changes.

Platform: Render hosted game / Windows 11 / Bazzite/Linux / other (specify).

Installation: Link to verified official download and upgrade instructions.

Known issues: Confirmed limitations.

Safety: State whether saves/worlds changed and what backup/testing was performed.

Future work: Development features remain separate from released features.
